# 网球学院运营文档

[XX网球学院]上课群的日常运营模板与规则，直接复制到微信群使用。
所有文件里方括号 `[ ]` 标出的都是需要按实际情况替换的参数。

## 文件

| 文件 | 内容 |
|---|---|
| [群规.md](群规.md) | 群规：报名、请假扣课时规则、补课、课时有效期、天气与场地、上课纪律 |
| [接龙模板.md](接龙模板.md) | 接龙模板：标准版 / 精简版 / 填写示例，以及请假、加课、补课三个配套接龙 |

## 怎么用

1. 先把 `群规.md` 里的参数（人数、费用、截止时间、课时有效期、联系人）按实际填好，作为**群公告**发一次，并置顶。
2. 每期课用 `接龙模板.md` 里的**精简版**发接龙；新课、调课或规则有变动时用**标准版**。
3. 规则调整后改这里的文件，再在群里发一次公告 —— 让文件始终是唯一的准确版本，避免群里翻聊天记录找旧规则。
